# JustNewMCP

[English README](../../README.md) · [Архитектура](./architecture.md)

Удаленный MCP сервер, который превращает любую чат-модель с поддержкой MCP в локального кодинг-агента. Написан на TypeScript под Bun 1.4+ для Linux и Windows, с авторизацией OAuth 2.1 и рабочей моделью по принципам Claude Code.

## Зачем мы это делаем

Чат-клиенты уже умеют подключать MCP, но большинство локальных серверов сводятся к сырому чтению и записи файлов. В итоге модель гадает пути, переписывает файлы целиком и работает без памяти и отката. JustNewMCP собирает недостающую среду в одном локальном сервере: ограниченные рабочие корни, точечные правки с чекпоинтами, память проекта, трекер задач и белый список команд.

## Статус

### Уже готово в `main`

- **Авторизация OAuth 2.1.** Встроенный сервер (`/.well-known/oauth-protected-resource`, `/.well-known/oauth-authorization-server`, `/oauth/authorize`, `/oauth/token`, `/oauth/revoke`) с PKCE S256, stateless `Bun.CSRF`, точным сравнением callback URI, одноразовыми кодами в терминале, SHA-256 хешированием токенов и rate limit по IP с проверкой доверенных прокси.
- **Инициализация воркспейса и индекс памяти.** `workspace_init` и `workspace_info` с привязкой к каноническому корню, защитой от симлинков, безопасным `git status` без `core.fsmonitor` и ограниченным чтением `MEMORY.md` до 25 КБ из `.justnewmcp/memory/` или общей папки `memoryDir`.
- **Файлы, поиск и чекпоинты.** `read_file` с нумерацией строк и проверкой UTF-8/бинарников, `edit_file` с обязательным чтением до правки, атомарный `multi_edit`, `write_file`, `glob_files` и `grep_files` с поддержкой `.gitignore`, а также `checkpoint_list` и `checkpoint_rewind` с правами `0700`/`0600` на POSIX.
- **Безопасная работа с `.env`.** Шаблоны вроде `.env.example` читаются по умолчанию. Реальные `.env` закрыты от прямого чтения и обслуживаются через `read_available_envs` с именами и длиной значений, `set_env_var` с многострочным парсером и чекпоинтами, плюс тумблеры `allowEnvReading` и `askHumanAllowance`.

### В разработке (Этап 1)

- **Белый список команд.** `run_allowed_cmd` через `Bun.spawn` с массивом `argv` без шелла, таймаутами и выгрузкой логов длиннее 30 тысяч символов на диск.
- **Задачи и режим плана.** Серверные `task_create`, `task_update`, `task_list`, `task_get` и программный read-only режим `plan_enter` и `plan_exit`.
- **Инструменты записи в память.** `memory_read`, `memory_write` и `memory_search` по тематическим папкам.
- **Автоматизация безопасности в CI.** CodeQL, Gitleaks, `bun audit` и Dependabot.

### В планах (Этап 2)

- Изолированные git worktree, фоновые процессы с `task_stop`, ленивая загрузка `tool_search`, диагностика через LSP и опциональный шелл, выключенный по умолчанию.
