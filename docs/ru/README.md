# JustNewMCP

[English README](../../README.md) · [Архитектура](./architecture.md)

Удаленный MCP сервер, который превращает любую чат-модель с поддержкой MCP в локального кодинг-агента. Написан на TypeScript под Bun для Linux и Windows, с авторизацией OAuth 2.1 и рабочей моделью по принципам Claude Code.

## Зачем мы это делаем

Чат-клиенты уже умеют подключать MCP, но большинство локальных серверов сводятся к сырому чтению и записи файлов. В итоге модель гадает пути, переписывает файлы целиком и работает без памяти и отката. JustNewMCP собирает недостающую среду в одном локальном сервере: ограниченные рабочие корни, точечные правки с чекпоинтами, память проекта, трекер задач и белый список команд.

## Запланированные модули

- **Авторизация OAuth 2.1.** Встроенный сервер авторизации с PKCE, одноразовым кодом подтверждения в локальном терминале, проверкой токенов через `crypto.timingSafeEqual` и лимитом попыток по IP.
- **Файлы и чекпоинты.** Рабочие папки строго внутри разрешенных корней, чтение по диапазону строк, точечный `edit` с проверкой уникальности фрагмента, `glob` и `grep` с учетом `.gitignore` и автоматические снимки файлов до каждой правки.
- **Память проекта и режим плана.** Индекс `MEMORY.md` под каждый репозиторий, серверный трекер задач и режим плана, в котором запись блокируется на уровне кода.
- **Белый список команд.** Никакого запуска через шелл. Команды стартуют как массив `argv` через `Bun.spawn` по локальному конфигу пользователя, а логи длиннее 30 тысяч символов выгружаются в файл на диске.
- **Второй этап.** Изолированные git worktree, фоновые процессы, подгрузка инструментов через `tool_search`, диагностика через LSP и опциональный шелл, выключенный по умолчанию.

## Статус

Ранняя разработка. Архитектура зафиксирована, следующим шагом собираем базовый сервер на Bun и OAuth 2.1.
